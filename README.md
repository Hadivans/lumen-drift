Lumen Drift — a neon arcade game: pilot a light-ship through the nebula, harvest golden light shards to build combos, dodge spiky void orbs, grab shield / magnet / slow-time power-ups, and climb levels that get faster and denser. Three hull hearts, a live HUD, synthesized sound, title / pause / game-over screens.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — mouse or WASD / arrows to fly, click or Space to start, P to pause, M to mute.
